# RentFlow — MATANGI CORPORATION

Personal rental-management dashboard for MATANGI CORPORATION.

## Included
- RentFlow dashboard matching the approved frontend style
- 15 preloaded rental/property records
- Tenant, property, rent and due-date management
- Manual WhatsApp reminders with pre-filled messages
- Multiple WhatsApp number selection for tenants with more than one number
- Reminder wording includes: “If you have already paid the rent, please ignore this payment reminder and kindly get your rent receipt.”
- Manual payment recording
- Automatic receipt generation after payment recording
- Print / Save receipt as PDF through the browser
- Excel export for rentals, payments and receipts
- Browser localStorage persistence

## WhatsApp
This version intentionally uses manual WhatsApp sending. Clicking WhatsApp opens WhatsApp with the message pre-filled; you manually press Send. No WhatsApp API or automatic sending is enabled.

## Data
The initial 15 records are preloaded in the browser. Changes are stored locally in the browser using localStorage.

## Deployment
This is a static website and can be deployed directly with GitHub Pages.
